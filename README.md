# Observation-Strategy-simulations
A framework for simulating supernova targets and optimizing observation strategies across the SOXS, MAST, and LDT spectrographs.
I have uploaded the ultrasat_targets_1year.csv file, so when you run the code on your computer, you will need to change the directory for this file
run in the terminal the next command to install all the needed reqiroments: pip install -r requirements.txt
please open the `input_path.txt` and paste the path to the CSV file
